## Approved agent key facts

- 5G adoption funnel: Data UU all (data_uu30_all) -> Data UU 5G device (data_uu30_dev_5g) -> 5G device with 5G traffic (dev5g_with_traffic).
- Step conversion: %5G-device = data_uu30_dev_5g/data_uu30_all; %5G-traffic = dev5g_with_traffic/data_uu30_dev_5g.
- 5G penetration = dev5g_with_traffic / dev5g_total. dev5g_no_traffic = punya HP 5G tapi belum pakai (funnel gap).
- traffic_5g = main 5G traffic metric. territory_level says aggregation grain.
- GRAIN -> TABLE (use ONLY these, never invent a table name): per-SITE -> rham_5g_site_monthly / rham_5g_site_daily; per-BRANCH -> rham_branch_5g_monthly / rham_branch_5g_daily; per-TERRITORY (circle/region/area/province) -> rham_5g_territory_monthly / _daily / _mtd (filter territory_level + territory_name). For 'funnel 5G per branch' use rham_branch_5g_monthly (GROUP BY branch). There is NO table rham_site_data_daily.
- Operational hierarchy from 2026-10: Circle > Region > Area > District. The former Area is abolished and its area/area_im3 column is NULL. New Area uses rham_ref_territory.branch_im3 or zz_territory_kecamatan.branch; new District uses micro_cluster_im3 or im3_mc. Alias branch AS area and micro_cluster_im3/im3_mc AS district in result columns. Legacy branch means current Area; MC/microcluster means District.
