## Flattened fact paths

- **`month_id_arithmetic`:** month_id is a STRING formatted 'YYYYMM' (e.g. '202605'). NEVER do integer math on it (month_id - 5 is WRONG and produces nonsense like '202600'). To go N months back, build a DATE then format: FORMAT_DATE('%Y%m', DATE_SUB(PARSE_DATE('%Y%m', (SELECT MAX(month_id) FROM <tbl>)), INTERVAL N MONTH)). Comparisons work fine via lexicographic string compare because zero-padded.
