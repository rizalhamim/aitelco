TABEL KHUSUS UNTUK QUERY KOORDINAT / PETA
================================================================================
Query koordinat/"terdekat"/"radius"/"peta" -> Router paksa ke site_performance,
SQL Agent diberi tambahan tabel lintas-domain:
  rham_site_wise_addr_java     <- REFERENSI UTAMA (koordinat lat/lon STRING + territory)
  rham_site_wise_monthly       <- revenue/subs/usage (bulanan)
  rham_site_wise_daily         <- revenue/subs/usage (harian)
  rham_5g_site_monthly         <- traffic/coverage 5G
  rham_site_fwa_daily          <- FWA
  rham_avail_stat_site_monthly <- availability 4G/5G
Pattern: addr_java JOIN tabel performance ON site_id.
PENTING: latitude & longitude di addr_java bertipe STRING -> wajib SAFE_CAST(... AS FLOAT64).
