Yang baru di Peta Agent

  • Peta dan chat dalam satu layar: panel chat di kanan (web) atau bottom sheet yang bisa ditarik (Android).
  • Setiap jawaban agent menambah layer: choropleth kecamatan, titik koordinat site, atau poligon. Layer bisa dinyalakan, dimatikan, dan diatur opasitasnya.
  • Upload SHP (.zip), GeoJSON, KML, atau CSV lat/long, lalu tanya tentang area itu. Contoh di sini: 17 site di dalam poligon upload.
  • Batas kecamatan memakai data asli Kab. Garut dari repo (42 kecamatan). Angka payload dan lokasi site masih ilustrasi.
  • Revisi 1 Nov: peta tidak hanya payload. Pilihan "Warnai peta dengan" berisi Performance (payload, revenue, availability), Site productivity (revenue, RGU 90D, VLR per site, bisa per tipe site), dan Profile wilayah (market share, pelanggan, gross add, penetrasi FWA).
  • Klik kecamatan membuka kartu yang merangkum Performance, Site productivity, dan Profile sekaligus. Klik titik merah membuka kartu site.
  • Hasil bisa diekspor GeoJSON atau PNG.
Yang perlu kamu cek: pembagian peta dan chat, isi panel layer, cara upload SHP, dan apakah halaman ini disetujui sebelum lanjut ke 06 Laporan.
